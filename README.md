# سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

سامانه تحت وب PHP/MySQL برای ثبت، پایش، تکمیل، جستجو، و گزارش‌گیری تجهیزات دانشگاه.

## امکانات نهایی
- ورود امن با نشست و CSRF و چهار نقش: مدیر، برداشت‌کننده، مشاهده‌کننده، کارشناس
- مدیریت کاربران و نقش‌ها توسط مدیر
- ثبت رایانه، چاپگر، نمایشگر و اسکنر
- ثبت اولیه از CSV خروجی پایش و تکمیل دستی اطلاعات
- پشتیبانی از مقادیر چندگانه جداشده با `|`
- استخراج ساختاری دیسک‌ها و RAM و امکان ویرایش آن‌ها
- شماره اموال دقیقاً ۷ رقمی و یکتا
- انتخاب کاربر/مسئول از جدول پرسنل
- ورود گروهی پرسنل از CSV با نگاشت نام فارسی و انگلیسی ستون‌ها
- جستجو، فیلتر و صفحه‌بندی فهرست تجهیزات و پرسنل
- پرونده کامل هر تجهیز و دریافت CSV منبع فقط پس از ورود
- ثبت رویدادهای عملیاتی در `audit_logs`
- گزارش جامع و خروجی CSV
- ذخیره امن فایل‌های منبع خارج از دسترسی مستقیم وب
- تراکنش هنگام ویرایش تجهیزات و اجزای آن‌ها
- GitHub Actions برای بررسی syntax فایل‌های PHP

## نصب
1. PHP 8.2+، MySQL 8+ و وب‌سروری با document root روی `public/` فراهم کنید.
2. `database/schema.sql` را روی MySQL اجرا کنید.
3. مقادیر اتصال DB را با متغیرهای `IHW_DB_DSN`، `IHW_DB_USER` و `IHW_DB_PASS` تنظیم کنید؛ یا تنظیمات پیش‌فرض `config/config.php` را تغییر دهید.
4. دسترسی نوشتن PHP به `storage/uploads/` بدهید.
5. برای ساخت مدیر: `php bin/create_admin.php admin 'رمز-حداقل-۸-کاراکتر' 'مدیر سامانه'`
6. آدرس سایت را به `public/` تنظیم کنید.

## ساختار
- `public/` صفحات وب و نقطه ورود
- `app/` bootstrap و سرویس‌های برنامه
- `database/` ساختار پایگاه داده
- `storage/uploads/` فایل‌های منبع خصوصی
- `bin/` ابزارهای مدیریتی خط فرمان

## نقش‌ها
- **مدیر:** مدیریت کاربران، پرسنل، تجهیزات، گزارش‌ها و رویدادها
- **برداشت‌کننده:** ثبت و ویرایش تجهیزات
- **کارشناس:** ثبت و ویرایش تجهیزات
- **مشاهده‌کننده:** مشاهده، جستجو و گزارش‌گیری بدون ویرایش

## نکات داده‌ای
`assets.technical` برای فیلدهای متغیر و تخصصی هر گروه استفاده می‌شود؛ اجزای تکرارشونده دیسک و RAM در جداول جداگانه نگهداری می‌شوند. شماره اموال در سطح کل سامانه یکتا است تا به‌عنوان کلید اصلی باقی بماند.
