# سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

سامانه ماژولار PHP 8.2+/MySQL برای پایش و ثبت تجهیزات رایانه، چاپگر، نمایشگر و اسکنر.

## ساختار

- `app/` هسته برنامه، احراز هویت، مجوزها و سرویس‌های دامنه
- `config/` تنظیمات
- `database/` اسکریپت‌های پایگاه داده
- `public/` ورودی وب و دارایی‌های رابط کاربری
- `storage/uploads/` فایل‌های ورودی و پیوست‌ها
- `views/` قالب‌های RTL

## نقش‌ها

`admin` مدیر، `collector` برداشت‌کننده، `viewer` مشاهده‌کننده، `expert` کارشناس.

## راه‌اندازی

1. PHP 8.2+ و MySQL 8+ نصب شود.
2. `database/schema.sql` اجرا شود.
3. تنظیمات اتصال در `config/config.php` یا متغیرهای محیطی تنظیم شود.
4. Document Root وب‌سرور روی `public/` قرار گیرد.
5. `storage/uploads` باید writable باشد.
6. برای ساخت مدیر اولیه، اسکریپت `bin/create_admin.php` استفاده شود.

## منبع فیلدها

فیلدهای سامانه بر اساس فرم Word پروژه و ساختار CSV نمونه طراحی شده‌اند؛ واردکننده CSV از مقادیر چندتایی و ساختارهای Disk/RAM پشتیبانی می‌کند.
