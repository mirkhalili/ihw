# سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

**نسخه فعلی: 0.1.0.2**

سامانه تحت وب PHP/MySQL برای ثبت، پایش، تکمیل، جستجو، و گزارش‌گیری تجهیزات.

## امکانات
- چهار بخش مستقل: کامپیوتر، چاپگر، نمایشگر و اسکنر
- فرم ثبت اختصاصی برای هر بخش؛ پس از تحلیل CSV فقط فیلدهای مرتبط با نوع انتخاب‌شده نمایش داده می‌شوند
- ثبت مرحله‌ای با امکان **رد شدن از هر مرحله** در صورت نبود تجهیز؛ فقط مراحل تکمیل‌شده در تأیید نهایی ثبت می‌شوند
- داشبورد با فهرست‌های جداگانه چهار نوع تجهیز
- ورود امن با نشست و CSRF و چهار نقش: مدیر، برداشت‌کننده، مشاهده‌کننده، کارشناس
- تعریف کاربران برداشت اطلاعات توسط مدیر و تعیین دسترسی ثبت/ویرایش جداگانه برای هر چهار بخش
- اتصال مدیریتی به Active Directory از طریق LDAP/LDAPS و همگام‌سازی پرسنل
- اطلاعات مسئول تجهیز از جدول پرسنل همگام‌شده با AD انتخاب می‌شود
- ثبت اولیه از CSV خروجی HWiNFO و تکمیل دستی اطلاعات
- مقادیر آرایه‌ای جداشده با `|` هنگام ورود به JSON معتبر تبدیل می‌شوند و در فرم ویرایش قابل اصلاح هستند
- چاپگر: شماره اموال، مکان و کاربر به‌صورت دستی؛ `PrinterCount`، `DefaultPrinterName`، `PrinterNames`، `PrinterPorts`، `PrinterDrivers`، `DuplexPrinters` و `PrinterDetails` از CSV استخراج می‌شوند
- اسکنر: شماره اموال، مکان و کاربر به‌صورت دستی؛ `ScannerCount`، `ScannerNames`، `ScannerManufacturers` و `ScannerDetails` از CSV استخراج می‌شوند
- `PrinterDetails` و `ScannerDetails` با جداکننده `||` پردازش می‌شوند و ورودی‌های Adobe از داده‌های چاپگر حذف می‌شوند؛ Microsoft Print to PDF، Fax و Send To OneNote حذف نمی‌شوند
- در ثبت چاپگر و اسکنر، MAC از CSV وارد نمی‌شود
- اطلاعات شبکه کامپیوتر فقط از فیلد «جزئیات کامل شبکه» نمایش داده می‌شود و اطلاعات تکراری ارائه نمی‌شوند
- اطلاعات `MonitorDetails` در بخش نمایشگر نگهداری می‌شود و به‌عنوان peripheral کامپیوتر نمایش داده نمی‌شود
- استخراج ساختاری دیسک‌ها و RAM برای کامپیوترها
- شماره اموال دقیقاً ۷ رقمی و یکتا؛ بررسی تکراری بودن هنگام ورود و قبل از ثبت نهایی انجام می‌شود
- جدول مستقل `usage_stats` برای ۱۶ شاخص آماری استفاده + شماره اموال، شامل بوت، خاموشی، جلسات و زمان جمع‌آوری
- جستجو، فیلتر و صفحه‌بندی فهرست تجهیزات و پرسنل
- پرونده کامل هر تجهیز و دریافت CSV منبع فقط پس از ورود
- ثبت رویدادهای عملیاتی در `audit_logs`
- گزارش جامع و خروجی CSV
- ذخیره امن فایل‌های منبع خارج از دسترسی مستقیم وب
- GitHub Actions برای بررسی syntax فایل‌های PHP

## نصب
1. PHP 8.2+، MySQL 8+ و وب‌سروری با document root روی `public/` فراهم کنید.
2. `database/schema.sql` را روی نصب جدید اجرا کنید.
3. برای نصب موجود، migrationهای `001`، `002`، `003`، `004_usage_stats.sql` و در صورت بروز خطای نبود جدول `006_usage_stats_repair.sql` را به ترتیب اجرا کنید. migrationهای repair را می‌توان دوباره اجرا کرد.
4. PHP باید افزونه LDAP را فعال داشته باشد (`ldap` و در صورت استفاده از LDAPS، گواهی CA معتبر سرور).
5. مقادیر اتصال DB را با متغیرهای `IHW_DB_DSN`، `IHW_DB_USER` و `IHW_DB_PASS` تنظیم کنید.
6. برای ساخت مدیر: `php bin/create_admin.php admin 'رمز-حداقل-۸-کاراکتر' 'مدیر سامانه'`
7. دسترسی نوشتن PHP به `storage/uploads/` بدهید.
8. آدرس سایت را به `public/` تنظیم کنید.

## نسخه‌بندی و دانلود
نسخه نرم‌افزار در فایل `VERSION` با قالب چهاررقمی نگهداری می‌شود. هر تغییر قابل تحویل نسخه جدید باید شماره نسخه را افزایش دهد؛ بنابراین برای دانلود نسخه آزمایشی فعلی، از شاخه `develop` و شماره **0.1.0.2** استفاده کنید.

## تنظیم Active Directory
مدیر پس از ورود از بخش **Active Directory**، سرور، Port، Base DN، حساب Bind، رمز و LDAP Filter را ثبت می‌کند؛ سپس «تست اتصال» و «همگام‌سازی پرسنل از AD» را اجرا می‌کند. رمز Bind در پایگاه داده به‌صورت رمزنگاری‌شده نگهداری می‌شود. برای کلید رمزنگاری بهتر است متغیر `IHW_APP_KEY` در محیط اجرا تنظیم شود؛ در نبود آن، کلید پایدار از رمز DB مشتق می‌شود.

همگام‌سازی به‌صورت پیش‌فرض `employeeID` و در نبود آن `sAMAccountName` را به‌عنوان کد پرسنلی و `displayName`، `department` و `title` را به‌عنوان مشخصات اصلی می‌خواند.

## نقش‌ها
- **مدیر:** مدیریت کاربران، دسترسی‌ها، Active Directory، پرسنل، تجهیزات، گزارش‌ها و رویدادها
- **برداشت‌کننده:** ثبت/ویرایش فقط بخش‌هایی که مدیر اجازه داده است
- **کارشناس:** ثبت/ویرایش فقط بخش‌هایی که مدیر اجازه داده است
- **مشاهده‌کننده:** مشاهده، جستجو و گزارش‌گیری بدون ویرایش

## ساختار
- `public/` صفحات وب
- `app/` bootstrap و سرویس‌ها
- `app/Services/ActiveDirectory.php` اتصال و همگام‌سازی AD
- `database/` ساختار و migrationها
- `storage/uploads/` فایل‌های منبع خصوصی
- `bin/` ابزارهای مدیریتی خط فرمان
