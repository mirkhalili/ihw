# سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

**نسخه فعلی: 0.1.0.8**

سامانه تحت وب PHP/MySQL برای ثبت، پایش، تکمیل، جستجو، و گزارش‌گیری تجهیزات.

## مستندات جامع
مستندات فنی، فرایندی، امنیتی، دیتابیس، CSV، Wizard، نقش‌ها، Active Directory، استقرار، تست، عیب‌یابی و راهنمای ورود عامل انسانی/هوش مصنوعی در پوشه **`docs/`** قرار دارد. نقطه شروع: `docs/00-index.md`.

## امکانات
- چهار بخش مستقل: کامپیوتر، چاپگر، نمایشگر و اسکنر
- فرم ثبت اختصاصی برای هر بخش
- ثبت مرحله‌ای با امکان رد کردن مرحله در صورت نبود تجهیز
- داشبورد با فهرست‌های جداگانه چهار نوع تجهیز
- نشست، CSRF و چهار نقش: مدیر، برداشت‌کننده، مشاهده‌کننده، کارشناس
- تعیین دسترسی ثبت/ویرایش جداگانه برای هر چهار بخش
- اتصال مدیریتی به Active Directory از طریق LDAP/LDAPS و همگام‌سازی پرسنل
- ثبت اولیه از CSV خروجی HWiNFO و تکمیل دستی
- پشتیبانی از مقادیر pipe-separated و ذخیره آرایه‌ها به JSON
- چاپگر و اسکنر با مدل داده و نمایش مستقل
- MonitorDetails در پایه نمایشگر
- اطلاعات شبکه کامپیوتر بدون نمایش تکراری
- استخراج ساختاری دیسک‌ها و RAM
- شماره اموال دقیقاً ۷ رقمی و یکتا
- جدول مستقل `usage_stats` برای ۱۶ شاخص آماری استفاده
- جستجو، فیلتر و صفحه‌بندی
- پرونده تجهیز و دریافت کنترل‌شده CSV منبع
- audit_logs و registration_history
- گزارش و خروجی CSV
- storage خصوصی
- GitHub Actions برای syntax PHP

## نصب
1. PHP 8.2+، MySQL 8+ و وب‌سروری با document root روی `public/` فراهم کنید.
2. `database/schema.sql` را روی نصب جدید اجرا کنید.
3. برای نصب موجود migrationها را مطابق `docs/04-database.md` و `docs/11-deployment.md` اجرا کنید.
4. PHP باید افزونه LDAP را فعال داشته باشد.
5. متغیرهای `IHW_DB_DSN`، `IHW_DB_USER` و `IHW_DB_PASS` را تنظیم کنید.
6. برای ساخت مدیر: `php bin/create_admin.php admin 'رمز-حداقل-۸-کاراکتر' 'مدیر سامانه'`
7. دسترسی نوشتن PHP به `storage/uploads/` بدهید.
8. آدرس سایت را به `public/` تنظیم کنید.

## نسخه‌بندی
نسخه در `VERSION` با قالب چهارقسمتی نگهداری می‌شود. نسخه جاری این شاخه **0.1.0.7** است.

## Active Directory
مدیر از بخش مربوطه host، port، Base DN، Bind و filter را تنظیم و سپس test/sync را اجرا می‌کند. رمز Bind رمزنگاری‌شده نگهداری می‌شود و استفاده از `IHW_APP_KEY` توصیه می‌شود.

## نقش‌ها
- **مدیر:** مدیریت کاربران، دسترسی‌ها، AD، پرسنل، تجهیزات، گزارش‌ها و رویدادها
- **برداشت‌کننده:** ثبت/ویرایش بخش‌های مجاز
- **کارشناس:** ثبت/ویرایش بخش‌های مجاز
- **مشاهده‌کننده:** مشاهده و گزارش‌گیری بدون ویرایش
