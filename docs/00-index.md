# مستندات جامع سامانه سخت‌افزار دانشگاه آزاد اسلامی واحد یزد

## هدف
این پوشه مرجع اصلی فهم، نگهداری، توسعه، استقرار، تست و عیب‌یابی پروژه است. محتوای آن بر اساس وضعیت شاخه `develop` در زمان نسخه 0.1.0.4 نوشته شده است.

## ترتیب مطالعه
1. `01-architecture.md` — معماری و مرز مسئولیت‌ها
2. `02-business-processes.md` — فرایندهای کاری
3. `03-security.md` — امنیت
4. `04-database.md` — پایگاه داده و جداول
5. `05-data-model.md` — مدل داده و ارتباطات
6. `06-csv-import.md` — قرارداد CSV و تحلیل HWiNFO
7. `07-hardware-wizard.md` — Wizard ثبت مرحله‌ای
8. `08-roles-permissions.md` — نقش‌ها و دسترسی‌ها
9. `09-active-directory.md` — Active Directory
10. `10-files-and-pages.md` — نقشه فایل‌ها و صفحات
11. `11-deployment.md` — استقرار
12. `12-testing.md` — تست و معیار پذیرش
13. `13-operations-troubleshooting.md` — عملیات و عیب‌یابی
14. `14-versioning-and-change-guide.md` — نسخه‌بندی و توسعه
15. `15-ai-human-handoff.md` — راهنمای ورود عامل انسانی/هوش مصنوعی
16. `16-known-gaps.md` — مواردی که باید در توسعه بعدی بررسی شوند

## اصل مهم
این مستندات «شرح وضعیت پیاده‌سازی‌شده» هستند، نه فهرست آرزوها. هرجا رفتار مورد انتظار با کد فعلی یکسان نباشد، اختلاف باید در `16-known-gaps.md` ثبت شود و بدون تأیید تغییرات، به‌عنوان قابلیت موجود فرض نشود.

## مرجع کد
- رابط وب: `public/`
- منطق مشترک: `app/`
- سرویس‌ها: `app/Services/`
- پیکربندی: `config/`
- دیتابیس: `database/`
- ابزار CLI: `bin/`
- فایل‌های منبع خصوصی: `storage/uploads/`
- نسخه: `VERSION`
